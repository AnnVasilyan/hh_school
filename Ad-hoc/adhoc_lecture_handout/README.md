# Лекция: Ad-hoc аналитика (Школа Аналитиков hh.ru)

Ноутбук для лайвкодинга и синтетические данные к нему.

## Как запустить

1. Распакуйте архив.
2. Откройте `lecture_adhoc_livecoding.ipynb` в Jupyter, JupyterLab или VS Code.
3. Запустите ячейки по порядку.

Первая ячейка с кодом сама найдёт папку `data/` и доустановит недостающие пакеты.
Если Jupyter ещё не установлен: `pip install -r requirements.txt`, затем `jupyter lab`.

Google Colab: загрузите архив в Colab, выполните `!unzip adhoc_lecture_handout.zip`
и откройте ноутбук из распакованной папки (или просто запустите его, ноутбук найдёт данные сам).

## Что внутри

| Файл | Что это |
|---|---|
| `lecture_adhoc_livecoding.ipynb` | Ноутбук лекции: пять кейсов ad-hoc анализа |
| `data/incident_events.csv` | Попытки публикации вакансий (кейсы 1 и 2) |
| `data/impressions.csv`, `data/clicks.csv`, `data/responses.csv` | Воронка: показы, клики, отклики (кейс 3) |
| `data/product_daily.csv`, `data/employer_spend.csv` | Расход по продуктам и работодателям (кейс 4) |
| `data/experiment_clients.csv` | Клиенты эксперимента со скидками (кейс 5) |

Все данные синтетические. SQL выполняется локально через DuckDB, запросы написаны близко к диалекту Trino.
Некоторые запросы в ноутбуке оставлены пустыми: их пишем вместе на лекции.
